# API Restaurante

API REST desenvolvida em Node.js para gerenciamento de pratos de um restaurante.

## Tecnologias

- Node.js
- Express
- Nodemon
- Morgan
- Body-parser
- CORS
- MySQL module
- MariaDB

## Estrutura do prato

- id
- nome
- categoria
- preco

## Rotas

- GET `/prato`
- GET `/prato/:id`
- POST `/prato`
- PUT `/prato/:id`
- DELETE `/prato/:id`
